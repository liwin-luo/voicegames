Comment jouer à Count

  1. Appuie sur Commencer. Le premier nombre est un.
  2. Dis le nombre à l'écran, puis le suivant quand il arrive.
  3. Chaque nombre entendu dans l'ordre rapporte un point.
  4. La compte s'arrête à trente, ou quand les 60 secondes sont passées.

Count utilise le service vocal de Chrome pour transformer ta voix en texte. Cette page ne garde pas l'enregistrement. Ouvre-la dans Chrome pour ordinateur.

Questions sur Count

Count est-il gratuit ?

Oui. Tous les jeux de Voicegames sont gratuits, sans compte et sans téléchargement. Ouvre la page et joue.

Où fonctionne Count ?

Les jeux de parole ont besoin d'un micro et de Chrome pour ordinateur. Chrome envoie l'audio à son service vocal et affiche les mots sur la page.

Ma voix est-elle enregistrée ?

Non. Les jeux de volume mesurent l'intensité dans la page et ne gardent jamais l'audio. Les jeux de parole utilisent le service vocal intégré de Chrome pour afficher les mots à l'écran ; Voicegames ne reçoit ni ne stocke l'audio.

Et si je dis un nombre dans le désordre ?

Rien de grave — l'écran redemande le même nombre jusqu'à entendre le bon. Seul le bon ordre marque.

Faut-il le nombre exact ?

Presque suffit. Le jeu accepte les variantes courantes et les chiffres, donc compte naturellement.
