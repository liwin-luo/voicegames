더 큰 소리·스페이스·마우스를 위로 하면 풍선이 올라가요.

플레이 방법: Float 3D

  1. 시작을 누르고, 브라우저가 물으면 마이크를 허용하세요.
  2. 큰 소리일수록 풍선이 올라가고, 스페이스를 누르거나 마우스를 위아래로 움직여도 됩니다.
  3. 링 하나 통과마다 1점.
  4. 링에 닿으면 라운드 종료. 시간은 30초입니다.

풍선은 옆모습이고 링은 오른쪽에서 옵니다. Float 3D는 페이지 안에서 볼륨만 측정하고 녹음하지 않습니다.

Float 3D 자주 묻는 질문

Float 3D은 무료인가요?

네. Voicegames의 모든 게임은 무료이며 가입도 다운로드도 필요 없습니다. 페이지를 열고 바로 즐기세요.

Float 3D은 어디서 할 수 있나요?

최신 브라우저라면 데스크톱과 모바일 어디서든 됩니다. 스페이스바와 마우스로도 조작할 수 있어 마이크가 차단돼도 괜찮습니다.

내 목소리가 녹음되나요?

아니요. 볼륨 게임은 페이지 안에서 소리 크기만 측정할 뿐 오디오를 저장하지 않습니다. 발화 게임은 Chrome 내장 음성 인식으로 화면에 글자로 보여줄 뿐, Voicegames는 오디오를 받거나 저장하지 않습니다.

다른 3D 게임과 뭐가 다른가요?

볼륨이 단순한 온·오프가 아니라 높이 다이얼입니다. 클수록 높이 떠서, 섬세한 컨트롤이 승부를 가릅니다.

마우스로만 할 수 있나요?

네. 화면에서 마우스를 누른 채 위아래로 움직이면 풍선이 따라옵니다. 스페이스도 가능해요.
