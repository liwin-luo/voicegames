플레이 방법: Flap 3D

  1. 시작을 누르고, 브라우저가 물으면 마이크를 허용하세요.
  2. 소리·스페이스·마우스를 누르고 있으면 나방이 올라가고, 떼면 떨어져요.
  3. 틈새 하나를 통과할 때마다 1점.
  4. 벽·천장·바닥에 닿으면 라운드 종료. 시간은 30초입니다.

나방은 옆모습으로 보이고 틈새는 오른쪽에서 옵니다. Flap 3D는 페이지 안에서 볼륨만 측정하고 녹음하지 않습니다.

Flap 3D 자주 묻는 질문

Flap 3D은 무료인가요?

네. Voicegames의 모든 게임은 무료이며 가입도 다운로드도 필요 없습니다. 페이지를 열고 바로 즐기세요.

Flap 3D은 어디서 할 수 있나요?

최신 브라우저라면 데스크톱과 모바일 어디서든 됩니다. 스페이스바와 마우스로도 조작할 수 있어 마이크가 차단돼도 괜찮습니다.

내 목소리가 녹음되나요?

아니요. 볼륨 게임은 페이지 안에서 소리 크기만 측정할 뿐 오디오를 저장하지 않습니다. 발화 게임은 Chrome 내장 음성 인식으로 화면에 글자로 보여줄 뿐, Voicegames는 오디오를 받거나 저장하지 않습니다.

Flap 3D는 점수를 어떻게 얻나요?

틈새 하나 통과마다 1점. 30초 동안 연속으로 많이 통과해 보세요.

나방이 계속 떨어지는 이유는?

소리가 추진력이에요. 조용한 방에서는 가라앉습니다 — 소리나 스페이스를 유지하면 올라가요.
