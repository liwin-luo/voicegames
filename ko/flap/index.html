소리를 유지하면 나방이 올라가요.

플레이 방법: Flap

  1. 시작을 누르고 마이크를 허용하세요.
  2. 소리를 유지하면 나방이 올라갑니다. 조용해지면 떨어져요.
  3. 틈새 하나 통과마다 1점.
  4. 벽·천장·바닥에 닿으면 라운드 종료. 시간은 30초입니다.

Flap는 페이지 안에서 볼륨만 측정할 뿐, 음성 서비스로 전송하거나 녹음하지 않습니다. 나방과 벽은 이 사이트가 직접 그렸습니다.

Flap 자주 묻는 질문

Flap은 무료인가요?

네. Voicegames의 모든 게임은 무료이며 가입도 다운로드도 필요 없습니다. 페이지를 열고 바로 즐기세요.

Flap은 어디서 할 수 있나요?

최신 브라우저라면 데스크톱과 모바일 어디서든 됩니다. 스페이스바와 마우스로도 조작할 수 있어 마이크가 차단돼도 괜찮습니다.

내 목소리가 녹음되나요?

아니요. 볼륨 게임은 페이지 안에서 소리 크기만 측정할 뿐 오디오를 저장하지 않습니다. 발화 게임은 Chrome 내장 음성 인식으로 화면에 글자로 보여줄 뿐, Voicegames는 오디오를 받거나 저장하지 않습니다.

Flap와 Flap 3D의 차이는?

규칙은 같고 화면만 달라요. Flap는 픽셀 2D, Flap 3D는 같은 비행을 블록 입체 시점으로 한 버전입니다.
