플레이 방법: Puff

  1. 시작을 누르고 마이크를 허용하세요.
  2. 소리를 내는 동안 풍선은 초당 약 44픽셀씩 커집니다 — 클수록 고득점.
  3. 반 초만 조용해지면 크기가 점수로 확정되고 새 풍선이 시작됩니다.
  4. 풍선마다 터지는 크기가 숨겨져 있어요. 넘기면 그대로 폭발, 0점. 30초입니다.

Puff는 페이지 안에서 볼륨을 측정할 뿐, 전송도 녹음도 없습니다. 풍선과 폭발은 이 사이트의 그림입니다.

Puff 자주 묻는 질문

Puff은 무료인가요?

네. Voicegames의 모든 게임은 무료이며 가입도 다운로드도 필요 없습니다. 페이지를 열고 바로 즐기세요.

Puff은 어디서 할 수 있나요?

최신 브라우저라면 데스크톱과 모바일 어디서든 됩니다. 스페이스바와 마우스로도 조작할 수 있어 마이크가 차단돼도 괜찮습니다.

내 목소리가 녹음되나요?

아니요. 볼륨 게임은 페이지 안에서 소리 크기만 측정할 뿐 오디오를 저장하지 않습니다. 발화 게임은 Chrome 내장 음성 인식으로 화면에 글자로 보여줄 뿐, Voicegames는 오디오를 받거나 저장하지 않습니다.

터지는 지점은 어디인가요?

비밀입니다 — 풍선마다 48~112 사이로 다릅니다. 풍선의 숫자는 현재 크기고, 한계치가 비밀이에요.

터진 풍선은 페널티인가요?

자존심만 — 0점으로 터지고 곧바로 새 풍선이 나옵니다. 욕심은 부는 데 쓴 시간을 앗아갑니다.
