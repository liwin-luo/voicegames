플레이 방법: Racer

  1. 시작을 누르고 마이크를 허용하세요.
  2. 낮은 소리 왼쪽, 높은 소리 오른쪽. 방향키나 화면 좌우도 됩니다.
  3. 피할 때마다 +1점. 충돌하면 라운드 종료.
  4. 차량은 점점 빨라집니다. 30초입니다.

Racer는 페이지 안에서 음정을 측정합니다. 오디오는 기기를 떠나지 않고 아무것도 저장되지 않습니다. 도로와 차량은 이 사이트의 그림입니다.

Racer 자주 묻는 질문

Racer은 무료인가요?

네. Voicegames의 모든 게임은 무료이며 가입도 다운로드도 필요 없습니다. 페이지를 열고 바로 즐기세요.

Racer은 어디서 할 수 있나요?

최신 브라우저라면 데스크톱과 모바일 어디서든 됩니다. 스페이스바와 마우스로도 조작할 수 있어 마이크가 차단돼도 괜찮습니다.

내 목소리가 녹음되나요?

아니요. 볼륨 게임은 페이지 안에서 소리 크기만 측정할 뿐 오디오를 저장하지 않습니다. 발화 게임은 Chrome 내장 음성 인식으로 화면에 글자로 보여줄 뿐, Voicegames는 오디오를 받거나 저장하지 않습니다.

차는 차선에 고정되나요?

아니요 — 조향은 연속적입니다. 작은 수정이면 충분해요.

얼마나 빨라지나요?

피할 때마다 조금씩 빨라집니다 — 마지막 10초가 진짜 시험입니다.
