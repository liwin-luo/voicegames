문장의 모든 단어를 말하세요.

플레이 방법: Repeat

  1. 시작을 누르고 마이크를 허용하세요.
  2. 두 단어짜리 짧은 문장이 나옵니다. 예: "빨간 사과".
  3. 두 단어를 모두 말하세요. 전부 인식될 때만 점수가 올라가요.
  4. 정답마다 새 문장이 나옵니다. 제한은 60초.

Repeat는 Chrome의 음성 서비스로 목소리를 글자로 바꿉니다. 이 페이지는 녹음을 저장하지 않아요. 데스크톱 Chrome으로 열어주세요.

Repeat 자주 묻는 질문

Repeat은 무료인가요?

네. Voicegames의 모든 게임은 무료이며 가입도 다운로드도 필요 없습니다. 페이지를 열고 바로 즐기세요.

Repeat은 어디서 할 수 있나요?

발화 게임에는 마이크와 데스크톱 Chrome이 필요합니다. Chrome이 음성을 인식 서비스로 보내 페이지에 글자를 표시합니다.

내 목소리가 녹음되나요?

아니요. 볼륨 게임은 페이지 안에서 소리 크기만 측정할 뿐 오디오를 저장하지 않습니다. 발화 게임은 Chrome 내장 음성 인식으로 화면에 글자로 보여줄 뿐, Voicegames는 오디오를 받거나 저장하지 않습니다.

어순이나 추가 단어도 영향하나요?

문장의 모든 단어가 들리면 되고, 다른 말이 섞여도 무시됩니다. 자연스럽게 말해도 돼요. 순서가 틀리면 점수가 없습니다.

아이도 Repeat를 할 수 있나요?

읽기 워밍업으로 좋아요 — 짧은 문장, 문장당 시간 압박 없음, 들린 단어만 카운트. 함께 도전해 보세요.
