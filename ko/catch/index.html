플레이 방법: Catch

  1. 시작을 누르고 마이크를 허용하세요.
  2. 낮은 소리로 왼쪽, 높은 소리로 오른쪽 이동. 방향키나 화면 좌우 절반을 누르고 있어도 됩니다.
  3. 금화 +1, 파란 보석 +3, 폭탄을 잡으면 라운드 종료.
  4. 30초 동안 최고 기록에 도전하세요.

Catch는 페이지 안에서 볼륨과 음정을 측정합니다. 오디오는 기기를 떠나지 않고 아무것도 저장되지 않습니다. 바구니·금화·폭탄은 모두 이 사이트의 그림입니다.

Catch 자주 묻는 질문

Catch은 무료인가요?

네. Voicegames의 모든 게임은 무료이며 가입도 다운로드도 필요 없습니다. 페이지를 열고 바로 즐기세요.

Catch은 어디서 할 수 있나요?

최신 브라우저라면 데스크톱과 모바일 어디서든 됩니다. 스페이스바와 마우스로도 조작할 수 있어 마이크가 차단돼도 괜찮습니다.

내 목소리가 녹음되나요?

아니요. 볼륨 게임은 페이지 안에서 소리 크기만 측정할 뿐 오디오를 저장하지 않습니다. 발화 게임은 Chrome 내장 음성 인식으로 화면에 글자로 보여줄 뿐, Voicegames는 오디오를 받거나 저장하지 않습니다.

낮은 소리·높은 소리의 기준은?

허밍이나 "음—"은 낮은 소리로 왼쪽, 휘파람이나 "이—"는 높은 소리로 오른쪽입니다. 길게 뻗는 소리가 가장 잘 조작됩니다.

폭탄을 잡으면?

라운드가 즉시 끝나고 점수는 그대로 남습니다. 폭탄은 자주 떨어집니다 — 욕심내면 당합니다.
