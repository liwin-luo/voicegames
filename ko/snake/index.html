플레이 방법: Snake

  1. 시작을 누르고 마이크를 허용하세요.
  2. 뱀은 스스로 기어갑니다. 낮은 소리는 왼쪽으로, 높은 소리는 오른쪽으로 — 진행 방향 기준 회전입니다.
  3. 사과 하나당 +1점, 몸이 2칸 길어집니다.
  4. 벽이나 자기 몸을 물면 라운드 종료. 30초입니다.

Snake는 페이지 안에서 음정을 측정합니다. 오디오는 기기를 떠나지 않고 아무것도 저장되지 않습니다. 뱀과 사과는 이 사이트의 그림입니다.

Snake 자주 묻는 질문

Snake은 무료인가요?

네. Voicegames의 모든 게임은 무료이며 가입도 다운로드도 필요 없습니다. 페이지를 열고 바로 즐기세요.

Snake은 어디서 할 수 있나요?

최신 브라우저라면 데스크톱과 모바일 어디서든 됩니다. 스페이스바와 마우스로도 조작할 수 있어 마이크가 차단돼도 괜찮습니다.

내 목소리가 녹음되나요?

아니요. 볼륨 게임은 페이지 안에서 소리 크기만 측정할 뿐 오디오를 저장하지 않습니다. 발화 게임은 Chrome 내장 음성 인식으로 화면에 글자로 보여줄 뿐, Voicegames는 오디오를 받거나 저장하지 않습니다.

회전은 절대 방향인가요?

상대적입니다 — "왼쪽"은 항상 뱀 기준 왼쪽입니다. 낮은 소리 두 번이면 유턴입니다.
