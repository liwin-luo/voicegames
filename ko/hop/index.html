소리로 차오릅니다. 조용해지면 점프합니다.

플레이 방법: Hop

  1. 시작을 누르고 마이크를 허용하세요.
  2. 소리를 내면 차지 링이 차오릅니다 — 만충일수록 멀리 납니다.
  3. 조용해지는 순간 점프해 다음 기둥으로. 정중앙 착지는 +2.
  4. 협곡으로 떨어지면 라운드 종료. 30초입니다.

Hop는 페이지 안에서 볼륨을 측정할 뿐, 전송도 녹음도 없습니다. 기둥과 등반가는 이 사이트의 그림입니다.

Hop 자주 묻는 질문

Hop은 무료인가요?

네. Voicegames의 모든 게임은 무료이며 가입도 다운로드도 필요 없습니다. 페이지를 열고 바로 즐기세요.

Hop은 어디서 할 수 있나요?

최신 브라우저라면 데스크톱과 모바일 어디서든 됩니다. 스페이스바와 마우스로도 조작할 수 있어 마이크가 차단돼도 괜찮습니다.

내 목소리가 녹음되나요?

아니요. 볼륨 게임은 페이지 안에서 소리 크기만 측정할 뿐 오디오를 저장하지 않습니다. 발화 게임은 Chrome 내장 음성 인식으로 화면에 글자로 보여줄 뿐, Voicegames는 오디오를 받거나 저장하지 않습니다.

점프 세기는 어떻게 판단하나요?

틈 위의 숫자가 폭이고, 링이 차지량입니다 — 만충이면 약 400픽셀. 짧은 틈은 일찍 멈추세요.

출발한 기둥에 다시 착지해도 되나요?

네, 안전합니다 — 다만 점수는 없어요. 먼 기둥만 점수입니다.
