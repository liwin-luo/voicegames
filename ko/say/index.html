플레이 방법: Say it

  1. 시작을 누르고 마이크를 허용하세요.
  2. 단어 하나가 화면을 채웁니다. 또렷하게 말하세요.
  3. 인식되면 1점이 오르고 다음 단어가 나와요.
  4. 제한은 60초. 정지로 일찍 끝낼 수 있어요.

Say It는 Chrome의 음성 서비스로 목소리를 글자로 바꿉니다. 이 페이지는 녹음을 저장하지 않아요. 데스크톱 Chrome으로 열어주세요.

Say it 자주 묻는 질문

Say it은 무료인가요?

네. Voicegames의 모든 게임은 무료이며 가입도 다운로드도 필요 없습니다. 페이지를 열고 바로 즐기세요.

Say it은 어디서 할 수 있나요?

발화 게임에는 마이크와 데스크톱 Chrome이 필요합니다. Chrome이 음성을 인식 서비스로 보내 페이지에 글자를 표시합니다.

내 목소리가 녹음되나요?

아니요. 볼륨 게임은 페이지 안에서 소리 크기만 측정할 뿐 오디오를 저장하지 않습니다. 발화 게임은 Chrome 내장 음성 인식으로 화면에 글자로 보여줄 뿐, Voicegames는 오디오를 받거나 저장하지 않습니다.

말했는데 점수가 안 올라가요.

단어 전체를 또렷하게 말하세요. 아래 막대에 Chrome이 들은 글자가 표시됩니다. 화면의 단어와 비교해 다시 시도해 보세요.

다른 언어로도 할 수 있나요?

네 — 상단 바에서 사이트 언어를 바꾸면 단어도 함께 바뀝니다. 각 언어 버전은 해당 언어로 인식해요.
