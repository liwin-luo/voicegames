플레이 방법: Bricks

  1. 시작을 누르고 마이크를 허용하세요.
  2. 낮은 소리·높은 소리로 패들 이동. 공은 발사 전까지 패들에 함께 다닙니다.
  3. 외치기·스페이스·클릭으로 발사. 위쪽 금 벽돌 +3, 중간 +2, 아래 +1.
  4. 공을 떨어뜨리면 다시 외쳐서 발사하세요. 30초입니다.

Bricks는 페이지 안에서 볼륨과 음정을 측정합니다. 오디오는 기기를 떠나지 않고 아무것도 저장되지 않습니다. 벽·패들·공은 모두 이 사이트의 그림입니다.

Bricks 자주 묻는 질문

Bricks은 무료인가요?

네. Voicegames의 모든 게임은 무료이며 가입도 다운로드도 필요 없습니다. 페이지를 열고 바로 즐기세요.

Bricks은 어디서 할 수 있나요?

최신 브라우저라면 데스크톱과 모바일 어디서든 됩니다. 스페이스바와 마우스로도 조작할 수 있어 마이크가 차단돼도 괜찮습니다.

내 목소리가 녹음되나요?

아니요. 볼륨 게임은 페이지 안에서 소리 크기만 측정할 뿐 오디오를 저장하지 않습니다. 발화 게임은 Chrome 내장 음성 인식으로 화면에 글자로 보여줄 뿐, Voicegames는 오디오를 받거나 저장하지 않습니다.

공을 다시 발사하는 이유는?

외침이 서브입니다. 공이 떨어지면 좋은 위치로 이동해서 다시 외치세요 — 서브도 실력입니다.

어떤 벽돌이 가장 비싸요?

맨 위 금 벽돌 두 줄은 +3, 중간은 +2, 아래는 +1 — 공을 위에 유지하세요.
