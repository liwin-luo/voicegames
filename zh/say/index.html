玩法说明 Say it

  1. 点“开始”并允许麦克风。
  2. 屏幕上会出现一个单词，清楚地把这个词读出来。
  3. 识别匹配后得分 +1，下一个单词马上出现。
  4. 限时 60 秒，可随时点“停止”结束。

说单词使用 Chrome 的语音服务把语音转成文字，本页面不保存录音。请用电脑版 Chrome 打开。

Say it 常见问题

Say it免费吗？

免费。Voicegames 上的所有游戏都不要钱，无需注册、无需下载，打开页面就能玩。

Say it在哪些设备上能玩？

说话类游戏需要电脑版 Chrome 和麦克风。Chrome 会把音频发给它的语音服务，并把识别出的文字显示在页面上。

我的声音会被录音吗？

不会。音量类游戏只在页面内测量响度，不保存任何音频；说话类游戏使用 Chrome 内置语音服务把语音转成屏幕上的文字，Voicegames 不会收到也不会存储你的音频。

为什么读了却不得分？

用正常音量把整个单词读清楚。底部状态条会显示 Chrome 听到的内容，对照屏幕上的单词再试一次。

说单词可以用其他语言玩吗？

可以——用顶栏切换网站语言，单词表会跟着切换，每个语言版本都用该语言的语音识别。
