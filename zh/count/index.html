玩法说明 Count

  1. 点“开始”，第一个数字是“一”。
  2. 读出屏幕上的数字，出现下一个就读下一个。
  3. 按顺序每听对一个数字得 1 分。
  4. 数到三十或时间用完（60 秒）就结束。

数数使用 Chrome 的语音服务把语音转成文字，本页面不保存录音。请用电脑版 Chrome 打开。

Count 常见问题

Count免费吗？

免费。Voicegames 上的所有游戏都不要钱，无需注册、无需下载，打开页面就能玩。

Count在哪些设备上能玩？

说话类游戏需要电脑版 Chrome 和麦克风。Chrome 会把音频发给它的语音服务，并把识别出的文字显示在页面上。

我的声音会被录音吗？

不会。音量类游戏只在页面内测量响度，不保存任何音频；说话类游戏使用 Chrome 内置语音服务把语音转成屏幕上的文字，Voicegames 不会收到也不会存储你的音频。

数错顺序会怎样？

没关系——屏幕会一直停在当前数字，直到听到对的为止。只有按顺序数对才得分。

必须说得一字不差吗？

接近就行。游戏接受常见说法和数字形式（如“21”），自然地数就可以。
