玩法说明 Repeat

  1. 点“开始”并允许麦克风。
  2. 屏幕会出现一行两个词的短语，比如“红苹果”。
  3. 把两个词都说出来，只有完整听到整句才得分。
  4. 每答对一次换新的一行。限时 60 秒。

复述使用 Chrome 的语音服务把语音转成文字，本页面不保存录音。请用电脑版 Chrome 打开。

Repeat 常见问题

Repeat免费吗？

免费。Voicegames 上的所有游戏都不要钱，无需注册、无需下载，打开页面就能玩。

Repeat在哪些设备上能玩？

说话类游戏需要电脑版 Chrome 和麦克风。Chrome 会把音频发给它的语音服务，并把识别出的文字显示在页面上。

我的声音会被录音吗？

不会。音量类游戏只在页面内测量响度，不保存任何音频；说话类游戏使用 Chrome 内置语音服务把语音转成屏幕上的文字，Voicegames 不会收到也不会存储你的音频。

词序错了或多说词有影响吗？

整行的每个词都要被听到，多说其他词没关系，自然表达就行；但顺序错了不得分。

小孩可以玩复述吗？

它很适合当朗读热身：句子短、单行没有时间压力、只按听到的词计分。可以陪孩子一起玩。
