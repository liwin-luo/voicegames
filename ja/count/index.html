遊び方： Count

  1. スタートを押すと最初の数字は「一」。
  2. 画面の数を声に出し、次が出たら続けて言う。
  3. 順番に聞き取れるごとに1点。
  4. 三十に達するか60秒経つと終了。

Count は Chrome の音声サービスで声を文字に変えます。録音は保存しません。パソコン版 Chrome で開いてください。

Count のよくある質問

Countは無料ですか？

はい。Voicegames のゲームはすべて無料。アカウントもダウンロードも不要で、ページを開けば遊べます。

Countはどこで遊べますか？

発話系ゲームにはマイクとパソコン版 Chrome が必要です。Chrome が音声を認識サービスに送り、ページに言葉を表示します。

声は録音されますか？

いいえ。音量系ゲームはページ内で音の大きさを測るだけで、音声を保存しません。発話系ゲームは Chrome 内蔵の音声認識で画面に文字として表示するだけで、Voicegames が音声を受け取ったり保存したりすることはありません。

順番を間違えたら？

大丈夫——正しい数を聞き取るまで同じ数字が表示され続けます。順番どおりだけ加点です。

正確に言わないとだめ？

近似でもOK。よくある言い方や数字も受け付けますので、自然に数えれば大丈夫。
