遊び方： Repeat

  1. スタートを押してマイクを許可。
  2. 2語の短いフレーズが出ます、例：「あかい りんご」。
  3. 両方の単語を言う。全部聞き取れた点だけ入ります。
  4. 正解ごとに次のフレーズ。制限60秒。

Repeat は Chrome の音声サービスで声を文字に変えます。録音は保存しません。パソコン版 Chrome で開いてください。

Repeat のよくある質問

Repeatは無料ですか？

はい。Voicegames のゲームはすべて無料。アカウントもダウンロードも不要で、ページを開けば遊べます。

Repeatはどこで遊べますか？

発話系ゲームにはマイクとパソコン版 Chrome が必要です。Chrome が音声を認識サービスに送り、ページに言葉を表示します。

声は録音されますか？

いいえ。音量系ゲームはページ内で音の大きさを測るだけで、音声を保存しません。発話系ゲームは Chrome 内蔵の音声認識で画面に文字として表示するだけで、Voicegames が音声を受け取ったり保存したりすることはありません。

語順や余分な言葉は影響する？

フレーズの全単語さえ聞き取れれば周りの言葉は無視されます。自然な話し方でOK。順番が違うと入りません。

子どもでも遊べる？

音読のウォームアップに人気です——短いフレーズ、1行ごとの制限なし、聞き取れた語だけカウント。親子でどうぞ。
