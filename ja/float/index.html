大きい声で風船が上がり、黙ると落ちます。

遊び方： Float

  1. スタートを押してマイクを許可。
  2. 大きい声で風船が上がり、黙ると沈みます。
  3. 丸い穴を1つ抜けるごとに1点。
  4. 端に触れるとラウンド終了。時間は30秒。

Float はページ内で音量を測るだけで、音声サービスへの送信も録音もありません。風船も穴もこのサイトのオリジナル描画です。

Float のよくある質問

Floatは無料ですか？

はい。Voicegames のゲームはすべて無料。アカウントもダウンロードも不要で、ページを開けば遊べます。

Floatはどこで遊べますか？

最新のブラウザなら、パソコンでもスマホでも遊べます。スペースキーとマウスでも操作できるので、マイクがブロックされていても大丈夫。

声は録音されますか？

いいえ。音量系ゲームはページ内で音の大きさを測るだけで、音声を保存しません。発話系ゲームは Chrome 内蔵の音声認識で画面に文字として表示するだけで、Voicegames が音声を受け取ったり保存したりすることはありません。

Float はヘリコプターゲームと同じ？

同じ「ワンボタン」系ですが、ボタンの代わりに声を使い、グラフィックは全部このサイトのオリジナルです。

黙ると風船が急に落ちるのはなぜ？

意図的に重力の方が強くしてあります——完全に黙るより、小さな声を続けるのが安全です。
