Catch

バスケットを動かし、コインと宝石を取って爆弾を避けます。

遊び方： Catch

  1. スタートを押してマイクを許可。
  2. 低い声でバスケットは左、高い声で右へスライド。矢印キーや画面の左右半分を押す操作でも動かせます。
  3. コインは1点、青い宝石は3点。爆弾を取るとラウンド終了。
  4. 時間は30秒。自己ベストを狙おう。

Catch はページ内で音量と音程を測るだけで、音声は端末から出ず、録音も保存もされません。バスケットもコインもこのサイトのオリジナル描画です。

Catch のよくある質問

Catchは無料ですか？

はい。Voicegames のゲームはすべて無料。アカウントもダウンロードも不要で、ページを開けば遊べます。

Catchはどこで遊べますか？

最新のブラウザなら、パソコンでもスマホでも遊べます。スペースキーとマウスでも操作できるので、マイクがブロックされていても大丈夫。

声は録音されますか？

いいえ。音量系ゲームはページ内で音の大きさを測るだけで、音声を保存しません。発話系ゲームは Chrome 内蔵の音声認識で画面に文字として表示するだけで、Voicegames が音声を受け取ったり保存したりすることはありません。

低音・高音の基準は？

ハミングや「うー」は低音で左へ、口笛や「いー」は高音で右へ。伸ばした声が一番操作しやすいです。

爆弾を取るとどうなる？

ラウンドは即終了、スコアはそのまま残ります。爆弾はよく落ちるので欲張りは要注意。
