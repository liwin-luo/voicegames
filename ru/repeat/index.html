Как играть в Repeat

  1. Нажми Старт и разреши микрофон.
  2. Появляется короткая фраза из двух слов, например «красное яблоко».
  3. Скажи оба слова. Очко только когда вся фраза услышана.
  4. Каждый раз приходит новая фраза. У тебя 60 секунд.

Repeat использует голосовой сервис Chrome, чтобы превратить речь в текст. Эта страница не хранит запись. Открой её в Chrome для компьютера.

Вопросы о Repeat

Repeat бесплатна?

Да. Все игры Voicegames бесплатны — без аккаунта и без загрузок. Открой страницу и играй.

Где работает Repeat?

Речевым играм нужны микрофон и Chrome для компьютера. Chrome отправляет аудио в свой голосовой сервис и показывает слова на странице.

Записывается ли мой голос?

Нет. Игры на громкость измеряют уровень прямо на странице и никогда не сохраняют аудио. Речевые игры используют встроенное распознавание Chrome, чтобы показать слова на экране; Voicegames не получает и не хранит аудио.

Важны ли порядок и лишние слова?

Все слова фразы должны быть услышаны; лишние игнорируются. Неверный порядок очков не даёт.

Дети могут играть в Repeat?

Отличная разминка для чтения: короткие фразы, без давления времени, счёт идёт по услышанным словам.
