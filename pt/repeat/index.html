Como jogar Repeat

  1. Pulse Começar e permita o microfone.
  2. Aparece uma frase curta de duas palavras, como "maçã vermelha".
  3. Diga as duas palavras. Só pontua a frase completa.
  4. Cada acerto traz uma frase nova. Você tem 60 segundos.

O Repeat usa o serviço de voz do Chrome para virar texto. Esta página não guarda a gravação. Abra no Chrome para computador.

Perguntas sobre Repeat

Repeat é grátis?

Sim. Todos os jogos do Voicegames são grátis, sem conta e sem download. Abra a página e jogue.

Onde Repeat funciona?

Os jogos de fala precisam de microfone e Chrome para computador. O Chrome envia o áudio ao serviço de voz dele e mostra as palavras na página.

Minha voz é gravada?

Não. Os jogos de volume medem a intensidade na página e nunca guardam áudio. Os jogos de fala usam o serviço de voz do Chrome para transformar som em texto na tela; o Voicegames nunca recebe nem armazena o áudio.

Ordem e palavras extras importam?

Todas as palavras da frase devem ser ouvidas; as extras são ignoradas. Ordem errada não pontua.

Crianças podem jogar Repeat?

É um ótimo aquecimento de leitura: frases curtas, sem pressão de tempo e o placar conta palavras ouvidas. experimentem juntos.
