Como jogar Voice acting

  1. Pulse Começar e permita o microfone.
  2. Um humor aparece sobre uma linha original, como sussurro ou raiva.
  3. Diga a linha — e represente o humor ao fazê-lo.
  4. O placar conta as palavras. O humor é seu. Você tem 60 segundos.

Esta página não ouve se você soou bravo ou calmo, então não pontua a interpretação — só confere as palavras. As linhas são escritas para este jogo. O Voice Acting usa o serviço de voz do Chrome e não guarda a gravação.

Perguntas sobre Voice acting

Voice acting é grátis?

Sim. Todos os jogos do Voicegames são grátis, sem conta e sem download. Abra a página e jogue.

Onde Voice acting funciona?

Os jogos de fala precisam de microfone e Chrome para computador. O Chrome envia o áudio ao serviço de voz dele e mostra as palavras na página.

Minha voz é gravada?

Não. Os jogos de volume medem a intensidade na página e nunca guardam áudio. Os jogos de fala usam o serviço de voz do Chrome para transformar som em texto na tela; o Voicegames nunca recebe nem armazena o áudio.

Representar o humor muda minha pontuação?

Não — o placar só confere as palavras. O humor existe para diversão e para treinar o registro.

Serve para testes ou demos de voz?

Como aquecimento é perfeito: humores aleatórios, linhas curtas, um minuto no relógio. Para gravações reais use um estúdio — esta página não guarda áudio.
