Como jogar Count

  1. Pulse Começar. O primeiro número é um.
  2. Diga o número na tela e o seguinte quando aparecer.
  3. Cada número ouvido na ordem soma um ponto.
  4. A conta para em trinta, ou quando os 60 segundos acabam.

O Count usa o serviço de voz do Chrome para virar texto. Esta página não guarda a gravação. Abra no Chrome para computador.

Perguntas sobre Count

Count é grátis?

Sim. Todos os jogos do Voicegames são grátis, sem conta e sem download. Abra a página e jogue.

Onde Count funciona?

Os jogos de fala precisam de microfone e Chrome para computador. O Chrome envia o áudio ao serviço de voz dele e mostra as palavras na página.

Minha voz é gravada?

Não. Os jogos de volume medem a intensidade na página e nunca guardam áudio. Os jogos de fala usam o serviço de voz do Chrome para transformar som em texto na tela; o Voicegames nunca recebe nem armazena o áudio.

E se eu disser um número fora de ordem?

Nada de mais — a tela segue pedindo o mesmo número até ouvir o certo. Só a ordem correta soma.

Preciso dizer o número exato?

Quase vale. O jogo aceita variações comuns e dígitos, então conte com naturalidade.
